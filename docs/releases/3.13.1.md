## What's new in 3.13.1

**Surgery**
- Implants are installed into the patient instead of lying on top. A seated implant shows only where the wound is open and sits in its socket mount. When you close up, it disappears under the skin, apart from the parts meant to stay visible: a neural jack, an optic's lens. The wiring and anchors are covered by the closed skin too.
- The rotation marks line up with the socket. The target square frames the socket's own key slot and the notch rides the same circle, so "aligned" on screen is aligned in the socket at every zoom and window size.

Scoring, tolerances, risk, implant stats and costs are unchanged. Nothing in saves changed: the format is still version 5, so 3.13.0 saves load as before.

**Known limitations**
- Implants still use their inventory icons on the operating field; they blend in through clipping and covering, not new surgical art.
- This Windows build was built and smoke-tested automatically on a GitHub Windows runner, which has no GPU and uses software rendering. It has not been played by hand on Windows hardware.
- Tests run on Linux under Godot 4.3 with every push.
